# IT326 - Cardiovascular Disease

## Project Description
This project focuses on analyzing cardiovascular disease data using data mining techniques to better understand the patterns and characteristics associated with the disease. The project will apply classification to predict whether an individual has cardiovascular disease based on health and lifestyle related attributes, while clustering will be used to group individuals with similar characteristics. 

By combining these two techniques, the project aims to discover meaningful patterns in the dataset and gain a clearer understanding of the factors related to cardiovascular disease.

## Motivation
We chose cardiovascular disease as the focus of this project because it is a common and serious health condition that can be influenced by several medical and lifestyle factors. The selected dataset provides a wide range of attributes related to an individual’s health, making it suitable for exploring how these factors may be associated with cardiovascular disease. 

Working with this dataset also gives us the opportunity to apply data mining techniques to a real-world healthcare problem and gain practical experience in discovering useful patterns from medical data. It also highlights how technology and data mining can support the development of innovative healthcare solutions for understanding and managing cardiovascular disease.
